# Fable — дорожная карта до готовой игры

**Снимок кода:** `fable-rpg/main` после PR #15, merge commit `37154a830eab311d8ddf815f13b38bf745522be4` (28 октября 2026).  
**Назначение:** план продукта и реализации. Этот каталог не вводит новых игровых правил и не утверждает, что предложенные функции уже существуют в коде.

## Что показывает текущий этап

Fable уже имеет детерминированное headless-ядро боя и проверяемый серверный вертикальный срез. PR #15 добавил WebSocket-путь Player/GM поверх реального SimulationEngine: handshake с токеном и членством в кампании, ролевые projections, движение игрока, GM pause/outcome, rate limit на соединение, resume token и интерфейс persistence с in-memory реализацией.

**Это ещё не готовая игра.** Нет готового пользовательского интерфейса Player/GM/TV, production identity provider, долговременной database-backed persistence, полного набора игровых команд в сетевом API и законченного world/campaign loop. Сейчас можно подключить собственный тестовый клиент к запущенному прототипу с правильно настроенными auth/membership providers; это не означает, что уже опубликован сайт, куда игроки могут зайти и начать кампанию.

## Маркировка достоверности

- **VERIFIED** — подтверждено текущим исходным кодом/тестами или метаданными слитого PR.
- **REPORTED CHECK** — результат проверки, записанный в описании PR; при подготовке этого документа команды локально не запускались.
- **SOURCE FINDING** — следует из чтения конкретного кода; если не воспроизведено тестом, не называть runtime-багом.
- **DECISION REQUIRED** — нужно утвердить игровое/продуктовое поведение до реализации.
- **PROPOSAL** — рекомендуемый будущий дизайн, не действующее правило.
- **NOT VERIFIED** — требует повторной проверки по текущему main.

## Принцип планирования

Сначала доказать надёжный короткий цикл «подключиться → сыграть → получить результат → переподключиться», затем закрепить сохранение состояния и безопасность, после этого расширять мир, контент и удобство. Не строить мир, UI и AI поверх транспортного или игрового поведения, которое ещё не определено и не проверено.
